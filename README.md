# Hospital Management System – Django Project

A web application built using Django for managing hospital appointments, doctors, patients, and staff.

## Features
- Admin panel
- Appointment booking system
- Doctor/patient registration
- CRUD operations on hospital records

## Tech Stack
- Django
- SQLite3
- HTML, CSS (Bootstrap)

## Run Locally
```bash
git clone https://github.com/ashishchauhan1234/HospitalManagement
cd HospitalManagement
python manage.py runserver
